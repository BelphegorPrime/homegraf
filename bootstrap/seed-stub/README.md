# Your homelab repository (placeholder content)

> **This is the stub seed.** The bootstrap of the homegraf stack puts the real seed here (the tools homegraf needs, `homelab.py` and
> friends, with an inventory skeleton). You are looking at the stub because the bootstrap image was built without `seed/`:
> the map is empty and homegraf's write actions will not find their tools. Rebuild the image with the seed, or copy the tools in by hand.

What this repository is for: it describes your homelab (`inventory/`, `stacks/<app>/compose.yaml`). Komodo deploys what is merged to
`main`, and homegraf draws it and opens pull requests against it.
